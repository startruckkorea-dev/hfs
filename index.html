3북마크 누르기
HFS 창이 열리고 진행 상황이 거기에 뜹니다. 목록을 끝까지 자동으로 읽어 이 창으로 보내며, 로그인 화면이면 로그인만 하면 이어서 들어옵니다.
한 번 성공하면 다음부터는 연결 정보를 기억해 바로 읽습니다 · 안 되면 팝업의 「자세히 복사」를 IT 에 보내 주세요
크롬은 코드가 든 북마크(javascript:)에는 아이콘을 붙이지 않고 지구본을 보여 줍니다 — 브라우저 제약이라 페이지 쪽에서는 바꿀 수 없습니다. 벤츠 별 아이콘을 꼭 쓰려면 오픈소스 확장 Bookmark Icon Customizer로 북마크 아이콘을 지정할 수 있습니다. (이 페이지 자체의 탭 · 일반 북마크 아이콘은 APS 와 같은 벤츠 별입니다.)
flex.team 구성원 화면에서 F12 → Console 탭에 아래를 붙여 넣고 Enter (처음엔 allow pasting 을 먼저 입력하라고 할 수 있습니다).
flex.team 구성원 화면 → F12 → 네트워크 탭 → 필터 search-users → 목록을 끝까지 내린 뒤, 요청 목록에서 오른쪽 클릭 → 「모두 HAR로 저장(콘텐츠 포함)」 한 파일을 아래에 놓거나, 각 요청의 응답 내용을 복사해 붙여 넣으세요(여러 개를 이어 붙여도 됩니다).
HAR · JSON · TXT 파일을 끌어 놓거나 클릭해 고르기
여러 파일을 한 번에 넣어도 됩니다 · 같은 사람은 한 번만 셉니다
2. 팀 → Department(본부) 매핑
보고 구조 규칙
Department 와 같은 이름의 Flex 조직(Sales · CSP · PMM · F&C)의 장이 본부장, 각 팀의 장이 팀장, 「Star Truck Korea」의 장이 대표(RD)입니다.
팀원
Boss = 팀장 · Boss of Boss = 본부장 (본부가 없는 팀 — HR · Compliance 등 — 은 그 팀장)
팀장
Boss = 본부장(본부가 없으면 RD) · Boss of Boss = RD
본부장
Boss = RD · Boss of Boss = - · 행의 Department · Team 에 본부 이름을 함께 적음(예: Sales / Sales)
대표(RD)
- / -
Flex 에는 팀의 상위 조직 정보가 없어 여기서 정합니다. 바꾼 값은 이번 작업에만 쓰이고, 새로 가져오거나 새로고침하면 기본값으로 돌아갑니다.
EngName 바꾸기
EngName 은 자동으로 정합니다 — Flex 표시 이름이 영문 한 단어(Jimmy · Gina …)면 「표시 이름 + 성」, 아니면 Flex 영문 이름. 다르게 쓰고 싶은 사람만 골라 바꾸세요.
